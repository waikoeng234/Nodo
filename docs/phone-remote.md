# 手机远程

手机使用浏览器访问电脑上正在运行的 DSH Desktop；Nodo 的项目、任务和 Agent 继续运行在电脑上。不需要单独启动 `dsh web`，也不需要在手机安装 Nodo。

## 首次设置

目前自动配置支持 macOS 的 DSH Desktop，需要宿主提供 `webServer.getOrigin()` 和 `connection.authenticatedUrl()`。这两项宿主接口能力已在 Desktop 0.2.2-rc.1 验证，完整的手机 + Tailscale 链路尚未经过真实环境验证；设置页会检查当前宿主能力。其他系统暂不支持自动配置。

1. 电脑和手机安装 [Tailscale](https://tailscale.com/download)，登录同一账号，两端都连接。Android 会使用系统 VPN 通道，因此会替换原本正在运行的 VPN；需要同时使用原 VPN 的用户应先考虑这一限制。
2. 在电脑打开 **Nodo 设置 → 手机远程**。缺少 Tailscale 时点击安装；安装或连接后点击 **重新检查**。
3. 点击 **启用手机远程**。Nodo 自动读取这台电脑的私有域名并配置 Tailscale Serve，无需手填域名或端口。若出现授权步骤，点击 **打开 HTTPS 授权页**，启用 **HTTPS certificates**，保持可选的 **Tailscale Funnel** 关闭；返回 Nodo，点击 **已授权，继续配置**。
4. 状态变为 **手机远程已启用** 后点击 **连接手机**。手机连接 Tailscale，再用相机或浏览器扫描二维码；也可以复制完整登录链接到手机浏览器。
5. 在手机打开 Nodo，确认项目和会话与 Desktop 一致。关闭 Wi-Fi，用蜂窝网络再访问一次，即可验证跨网络连接。

登录二维码和链接授予整个 DSH 宿主的所有者权限，包括其可访问的文件和终端，不局限于 Nodo。只供本人设备使用，请勿分享、截图上传或贴进日志。Nodo 只保存启用状态、域名和本机代理端口，不保存登录链接。

## 日常使用

- 电脑保持联网、唤醒，DSH Desktop 保持运行；手机保持 Tailscale 连接，在浏览器收藏远程地址即可。
- 重开 Desktop 后，Nodo 会在 Tailscale 已连接且原转发仍存在时恢复本机代理；无法恢复时移除本功能的转发。若 Tailscale 稍后才连接，在设置页重新检查并启用即可。
- 浏览器已有有效登录状态时直接打开收藏地址。出现认证提示时，回到 Desktop 点击 **连接手机** 生成新链接；旧登录链接可能随宿主重启失效。
- 这项配置不更改 Tailscale 出口节点。它提供到电脑的私有连接；手机和 Mac 的其他代理、VPN 路由由各自系统及网络软件决定。

## 关闭与排错

在设置页点击 **关闭远程访问** 会移除本功能仍在使用的根路径转发并停止本机代理，不重置其他 Serve 路径，不退出 Tailscale。卸载或停用 Nodo 会停止本机代理；如需清除持久的 Serve 配置，请先在设置页关闭远程访问。

| 现象 | 处理 |
| --- | --- |
| 页面提示当前环境不支持 | 使用 macOS DSH Desktop，并更新到具备浏览器接入能力的版本 |
| 无法连接 Tailscale | 打开 Tailscale，确认已登录并连接，再重新检查 |
| 收包模块异常 / ReceiveIPv4 提示 | 完全退出再重新打开 Tailscale，连接后重新检查 |
| HTTPS 入口已用于其他服务或已开 Funnel | 先在 Tailscale 中处理原配置；Nodo 不覆盖其他服务，也不启用公网 Funnel |
| 本机转发启动失败 | 重新启用手机远程；上次异常退出残留的本机代理会自动清理，仍失败时检查系统 Apache（`/usr/sbin/httpd`）能否运行 |
| 手机超时 | 检查两端 Tailscale 是否连接、是否在同一网络，以及电脑是否休眠；自定义访问策略还需允许手机访问电脑的 HTTPS 服务 |
| authentication required | 生成新二维码或完整复制新的手机登录链接；只打开域名不会完成首次认证 |
