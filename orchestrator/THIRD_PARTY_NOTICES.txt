The panel renders its menus, dialogs, buttons, list rows, message rows, tool and
thinking rows, markdown, icons and form controls through
@deepseek-ai/dsh-client-ui-primitives (DeepSeek Harness), MIT licensed: the shell
seeds that package into the client module table for every plugin.

The panel also copies layout values (sizes, paddings, radii, gaps, type scale)
and the composer's send and stop glyph paths from the host's own client packages
(dsh-client-ui-conversation, dsh-client-ui-chat, dsh-client-ui-tool,
dsh-client-ui-sidebar, dsh-client-ui-workspace, dsh-client-ui-approval,
dsh-client-ui-user-questions, dsh-client-locale — all DeepSeek Harness, MIT
licensed) so its surfaces match the product they sit in.

The session identity MCP service uses @modelcontextprotocol/sdk 1.32.1,
the official Model Context Protocol TypeScript SDK, MIT licensed.
It is installed as an npm dependency with its license; protocol code is not copied.
